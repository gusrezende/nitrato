#   anomalia <pasta> <descrição>
#       começa uma anomalia. <pasta> é a pasta dentro de assets/anomalias/ com
#       os quadros alterados; a descrição aparece no dossiê quando ela é achada.
#
#   quadro <número> <x> <y> <largura> <altura>
#       um quadro em que a anomalia pode aparecer e a área clicável dele, em
#       pixels da imagem. O arquivo é assets/anomalias/<pasta>/frame_NNNN.png,
#       com o mesmo número do quadro normal que ele substitui.
#
#   area <x> <y> <largura> <altura>
#       mais uma área clicável para o quadro da linha anterior (até 4 por quadro).
#
# A cada partida o jogo sorteia quais anomalias entram e em qual dos quadros
# cadastrados cada uma fica (nunca duas no mesmo quadro).
# Salve este arquivo em UTF-8.
